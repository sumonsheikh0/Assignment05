Answare to the question no-1 
===============================

The difference between var, let, and const is there 

var- Old way to declare variables. It is function-scoped and can be redeclared and updated.

let- Newer way. It is block-scoped and can be updated but not redeclared in the same scope.

const- Also block-scoped, but cannot be updated or redeclared after assignment.

Answare to the question no-3 
===============================

the difference between map(), filter(), and forEach()

map(): Goes through each item in an array and returns a new array with the modified values.

filter(): Goes through the array and returns a new array with only the items that match a condition.

forEach(): Simply loops through the array and runs a function for each item, but does not create a new array.
